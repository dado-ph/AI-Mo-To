# Security policy

## Supported versions

Security fixes are provided for the current `main` branch and the most recent
released version, when a release exists.

## Report a vulnerability privately

Do not open a public issue for suspected vulnerabilities. Use GitHub's private
[security advisory form](https://github.com/dado-ph/AI-Mo-To/security/advisories/new).
Include a clear description, affected commit or version, reproduction steps,
impact, and any suggested mitigation. Please avoid including real secrets or
private workspace data.

We will acknowledge a report within five business days and work with you on a
fix and coordinated disclosure. If the advisory form is unavailable, contact
the repository owner through GitHub and ask for a private reporting channel.
